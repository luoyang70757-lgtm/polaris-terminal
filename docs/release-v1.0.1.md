# Polaris v1.0.1（2026-11-18）

> **版本号重置**：GitHub 上的历史 Releases 与 `v*` 标签已按用户要求清空（27 个 Release、27 个标签全部删除），版本号**从 1 重新开始**。本版代码内容 = 原 v1.0.29（不是新功能版，是「同一份代码 + 新的版本序列」）。

## 1. 这一版能做什么（能力清单）

- **终端**：多标签 SSH 会话、xterm.js 渲染、界面字号/字体全局跟随设置、10 套精选配色（Tabby/iTerm2 色板 + 对比度保底派生）、终端内链接 ⌘(mac)/Ctrl(Windows) 点击直达浏览器。
- **会话与分组**：会话列表/树形两种视图共用一套分组层级；三角折叠（列表/树形都能收）、搜索自动展开命中路径、`(直属/合计)` 计数、拖拽排序与「拖成子分组」、全键盘导航、启动一律折叠。会话支持密码（`safeStorage` 加密）、私钥/口令、`su - root` 提权。
- **导入**：`~/.ssh/config` 导入（`Host *` 继承、`~` 展开），**`ProxyJump` / `ProxyCommand` 也一并解析**（`[user@]host[:port]`、`ssh://…`、`ssh -p N … -W %h:%p`、`nc host port`），认不出来的写法会带 `⚠` 提示而不是静默丢跳板。
- **跳板机**：主会话隧道 + **一次性连接也走跳板**（批量执行、AI `run_command`、系统探测、连接测试），自己开隧道、`finally` 回收、不占用主会话槽位。
- **SFTP**：不再是内置面板，**唯一入口是「用本机 WinSCP 打开当前会话」**（工具栏 / ⌘⇧S / 菜单 / 标签右键 / 堡垒机资产）；起始目录自动取绝对路径（未知就现探家目录）、chroot 型服务端自动带 `SFTPRealPath=off`、跳板机走 WinSCP 原生 `Tunnel*` 隧道、拉起日志脱敏（口令一律 `***`）。
- **堡垒机**：JumpServer（API 对接 KoKo 网关，token 有效期 5 分钟余量、登录单飞、凭据错永久熔断免得打满「8 次锁 30 分钟」）与 H3C（webview 登录 + 主进程原生拉资产；RDP/存储类资产交给本机 `AccessClient.exe`）。资产分组默认折叠、非 SSH 资产有协议徽标与替代路径提示。
- **其它**：录制回放、全量日志（含「⬇ 下载日志」）、主机指纹校验与「信任并记住」、危险命令确认、自动锁定、命令补全与智能推荐、AI 助手/技能/知识库、检查更新、关于。
