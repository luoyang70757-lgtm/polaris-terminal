# Polaris v1.0.1（2026-11-03）

## 堡垒机浏览器显示优化

- **工具栏精简**：去掉重复的「🌐 堡垒机」标题，清除历史收进「⋯」更多菜单；
- **空态/加载/错误态结构化**：
  - 空闲：图标 + 标题 + 说明 +「配置堡垒机」；
  - 加载：只显示转圈，不再在空态里重复写“加载中…”；
  - 失败：显示具体错误 +「重试」（工具栏 ↻ 仍可用）；
- **「⋯」更多菜单**：在系统浏览器打开 / 复制当前地址 / 重置缩放 / 清除堡垒机历史；
- **缩放体验**：双击缩放百分比恢复 100%；拖动面板宽度后自动重新适配页面；
- **空间利用**：无页面标题时自动隐藏当前页信息行，webview 加载前使用面板底色，减少白闪。

新增 `app:openExternal` IPC，仅允许 `http/https`，防止任意本地/危险协议被打开。

## 自动更新

本版本继续提供 Windows 安装版自动更新。已安装 **v1.0.0** 的用户应能在
「帮助 → 检查更新」看到 v1.0.1，并可直接下载、重启安装。
