## 1.0.57 — 修复与回归

- **修真实 bug**：`execOnSession` 在 ssh2 的 `exit` 事件就返回，此时 stdout 还没读完 →
  打包上传探测总拿到空串，误判"主机不支持打包"，文件夹上传白白退化成逐文件传输。
  改为 exit 只记退出码、`close` 才 resolve。
- 回归脚本/mock 修缮：Windows 路径转义、tar 用系统 bsdtar、失败注入路径分隔符归一、
  webview 钩子断言按新架构重写、取消传输与下载失败的时序韧性。
- 全量回归：84 个脚本，**82 全绿 / 579 条断言**（`verify-pack-real` 需真实主机密码）。

## 1.0.56 — 主题精简 + 苹果字体

- 主题 25 → **10 套精选**（深空/浅色/Graphite/Mist/Solarized/Nord/Dracula/Catppuccin/Gruvbox/松雾），
  旧配置自动回落默认主题。
- **苹果字体支持**：界面字体栈改为 SF Pro / 苹方优先；新增「界面字体」设置

## 1.0.55 — 新建会话弹窗精简

- 默认只显示必要字段（名称 / 主机+端口 / 用户名+密码 / 分组 / 测试连接），
  协议、私钥、私钥口令、跳板机、终端编码、登录宏收进折叠的「高级选项」；
  编辑带高级设置的会话会自动展开。弹窗一屏放下，保存按钮无需滚动。

## 1.0.54 — 关于

## 1.0.53 — 界面布局与字体
